# Installing Vorath Infestation 0.1.0-alpha

You need **Minecraft Java 1.21.1**, **NeoForge 21.1.264** (or a later 21.1 build) and **GeckoLib 4.9.3** (or a later 4.x).
Other Minecraft versions do not work.

## With the Modrinth app

1. Create a new profile: Minecraft **1.21.1**, loader **NeoForge**.
2. Search for **Vorath Infestation** and install it. GeckoLib is added with it.
3. Play.

## With the CurseForge app

1. Create a new profile: Minecraft **1.21.1**, **NeoForge**.
2. Search for **Vorath Infestation** and install it. GeckoLib is added with it.
3. Play.

## By hand

1. Download the NeoForge installer for **21.1.264** (or later 21.1) from neoforged.net, run it, and choose "Install client".
2. Start Minecraft once with the new NeoForge profile, then close it.
3. Put `vorath-1.21.1-0.1.0-alpha.jar` and the GeckoLib jar for **NeoForge 1.21.1** (4.9.3 or later 4.x) into the `mods` folder
   of your Minecraft directory.
4. Start the NeoForge profile.

## Then

Create a **new world** (Survival, Normal). Your **field manual** is in your inventory: right-click it to read it.
A ship comes down nearby at night: the second night on standard, the first on nightmare, the third on calm.

Something wrong? [Report a bug](https://github.com/sebpost2/vorath-infestation-issues/issues/new?template=bug_report.md)
and attach `logs/latest.log`.
