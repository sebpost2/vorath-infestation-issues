# Installing Vorath Infestation 0.1.0-alpha

You need **Minecraft Java 26.2**, **NeoForge 26.2.0.88** (or a later 26.2 build) and **GeckoLib 5.5.6** (or a later 5.x).
Other Minecraft versions do not work.

## With the Modrinth app

1. Create a new profile: Minecraft **26.2**, loader **NeoForge**.
2. Search for **Vorath Infestation** and install it. GeckoLib is added with it.
3. Play.

## With the CurseForge app

1. Create a new profile: Minecraft **26.2**, **NeoForge**.
2. Search for **Vorath Infestation** and install it. GeckoLib is added with it.
3. Play.

## By hand

1. Download the NeoForge installer for **26.2.0.88** from neoforged.net, run it, and choose "Install client".
2. Start Minecraft once with the new NeoForge profile, then close it.
3. Put `vorath-0.1.0-alpha.jar` and the GeckoLib jar for **NeoForge 26.2** (5.5.6 or later 5.x) into the `mods` folder
   of your Minecraft directory.
4. Start the NeoForge profile.

## Then

Create a **new world** (Survival, Normal). Your **field manual** is in your inventory: right-click it to read it. About a
day into the world, a ship comes down nearby.

Something wrong? [Report a bug](https://github.com/sebpost2/vorath-infestation-issues/issues/new?template=bug_report.md)
and attach `logs/latest.log`.
